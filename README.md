# 🎓 CADI F1 - Cursos y Áreas de Estudio

Aplicación web interactiva que consume la API de CADI F1 para explorar las áreas de estudio, listar sus cursos e inspeccionar la información detallada de cada uno en tiempo real.

---

## 🌐 Demostración

👉 **[Live Demo](https://sebaxlandaeta.github.io/catalogo-cursos-cadif1/)**

---

## ⚡ Características

- 🔍 Exploración de áreas de estudio mediante peticiones asíncronas a la API de CADI F1.
- 📚 Carga dinámica de la lista de cursos asociados a cada área.
- 📄 Visualización detallada de la información de cada curso.
- 🌓 Personalización de modo claro y modo oscuro.
- 🚀 Desarrollo ligero con JavaScript Vanilla y CDN de Tailwind CSS, sin requerir empaquetadores ni pasos de compilación.

---
## 🛠️ Tecnologías Utilizadas

- 🌐 HTML5
- 🎨 Tailwind CSS (CDN)
- 🟨 JavaScript Vanilla (ES6+)
- 📡 Fetch API
